# 서울시 공영주차장 데이터 분석

헤더를 빼면 2,167행이고, 모든 행에 열이 39개씩 있습니다. 빈칸과 공백만 있는 칸을 누락으로 셌습니다. 숫자 `0`과 시각 `0000`은 값이 있는 칸으로 집계했습니다.

자치구와 1시간 요금은 원본에 별도 열이 없습니다. 주소의 첫 단어로 2,167행 모두 자치구를 확인할 수 있었습니다. 1시간 요금은 기본·추가 요금과 각각의 적용 시간을 이용해 계산하고, `int hourlyFee`에 저장합니다.

`ParkingNode`에는 정수 대신 `Parking`을 담습니다. 
로더는 CSV 한 행을 고정 배열 `std::string fields[MAX_FIELDS]`에 나눠 담고, 필요한 값을 꺼내 `Parking`을 만듭니다. 새 주차장은 `addParking()`으로 넣습니다. 이 함수에서 `new`로 노드를 만들고 `next`를 연결합니다. 사용이 끝난 리스트는 `destroyParkingList()`로 해제합니다.

- 코드 병합. 고유 코드는 831개다. 중복 코드 64개에 속한 1,400행은 모두 노상 주차장이며 각 행의 총 주차면은 1이다. 같은 코드 안에서 주차장명, 주소, 운영구분명, 유무료구분, 평일 운영시간과 기본·추가 요금 및 시간은 일치했다. 이 파일에서는 현재 로더의 면수 합산 규칙이 관측값과 맞는다.
- 요금. 기본요금이 빈 3행은 모두 무료이고, 기본요금이 0인 유료 행이 9개 있다. 기본 주차시간은 5분이 2,035행, 0분이 79행, 누락이 3행이며 다른 시간도 섞여 있다. 추가요금과 추가시간이 각각 75행에서 비어 있다.
- 시각. 평일 시작과 종료가 둘 다 `0000`인 행은 84개다. 이 조합의 운영 의미는 파일에서 확인할 수 없다.
- 인코딩. 첨부 원본을 현재 로더로 읽으려면 UTF-8 사본이 필요하다. 로더는 UTF-8 BOM을 처리하며 CP949를 변환하는 코드가 없다. 따옴표 안의 쉼표를 처리하는 기존 파서를 사용한다.
