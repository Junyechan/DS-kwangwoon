# 서울시 공영주차장 데이터 분석

프로그램이 읽는 [`data/parking.csv`](../data/parking.csv)를 기준으로 분석했습니다. 한글 헤더와 영문 컬럼명 행을 제외하면 **2,181행**이고, 각 행은 **40개 컬럼**으로 구성됩니다. 빈 문자열과 공백만 있는 값은 누락으로 집계했습니다. `0`, `0.0`, `0000`은 값이 있는 칸으로 셌습니다.

## 프로젝트에서 사용하는 컬럼

| 원본 컬럼 | 원본 값 형식과 예시 | C++ 자료형과 용도 | 누락 |
|---|---|---|---:|
| 주차장코드 | 숫자로 구성된 식별자 `1013181` | `std::string`, 같은 코드의 행을 병합하는 키 | 0 |
| 주차장명 | 한글 문자열 `마장동(건물) 공영주차장(구)` | `std::string name` | 0 |
| 주소 | 문자열 `성동구 마장동 463-2` | `std::string address`, 자치구 추출에 사용 | 0 |
| 총 주차면 | 정수(면) `52` | `int capacity`, 같은 코드의 면수 합산 | 0 |
| 기본 주차 요금 | 정수(원) `50` | `int basicFee`, 1시간 요금 계산에도 사용 | 0 |
| 기본 주차 시간(분 단위) | 정수(분) `5` | `int`, 1시간 요금 계산에 사용 | 0 |
| 추가 단위 요금 | 정수(원) `50` | `int`, 1시간 요금 계산에 사용 | 0 |
| 추가 단위 시간(분 단위) | 정수(분) `5` | `int`, 1시간 요금 계산에 사용 | 0 |
| 유무료구분명 | 문자열 `유료` 또는 `무료` | `std::string`, 유료 행의 요금 정보 판정에 사용 | 0 |
| 평일 운영 시작시각(HHMM) | 4자리 시각 `0000` | `std::string openTime`, 표시값 `00:00` | 0 |
| 평일 운영 종료시각(HHMM) | 4자리 시각 `2400` | `std::string closeTime`, 표시값 `24:00` | 0 |

자치구와 1시간 요금은 원본에 별도 컬럼이 없습니다. 2,181행 모두 주소의 첫 단어에서 자치구를 확인할 수 있었습니다. 로더는 자치구를 `std::string district`에 저장하고, 기본·추가 요금과 각각의 적용 시간으로 1시간 요금을 계산해 `int hourlyFee`에 저장합니다.

`ParkingNode`에는 `Parking` 객체를 저장합니다. 로더는 CSV 한 행을 `std::string fields[MAX_FIELDS]` 배열로 나눠 필요한 값으로 `Parking`을 만듭니다. 새 주차장은 `addParking()`으로 추가하고, 사용이 끝난 리스트는 `destroyParkingList()`로 해제합니다.

- **주차장코드 병합.** 고유 코드는 842개입니다. 중복 코드 64개에 속한 1,403행은 모두 노상 주차장이며 각 행의 총 주차면은 1입니다. 같은 코드 안에서는 순번과 위도·경도가 달랐고, 주차장명·주소·요금 등 나머지 값은 같았습니다. 로더는 처음 읽은 주차장 정보를 유지하고 이후 행의 주차면수를 더합니다.
- **요금.** 기본요금이 0원인 행은 무료 74행과 유료 9행입니다. 기본 주차시간은 5분이 2,048행, 0분이 82행입니다. 로더는 유료 행에서 계산한 1시간 요금이 0원이면 `FEE_UNKNOWN`으로 표시합니다.
- **시각.** 평일 시작과 종료가 둘 다 `0000`인 행은 84개입니다. 파일에는 이 조합의 운영 의미가 명시되어 있지 않습니다.
- **파일 형식.** `data/parking.csv`는 BOM이 있는 UTF-8 파일입니다. 로더는 BOM과 두 번째 줄의 영문 컬럼명을 건너뛰고, 따옴표로 감싼 헤더 안의 쉼표를 처리합니다.
