# DS-kwangwoon

광운대학교 자료구조 팀 프로젝트

---

## 1. 프로젝트 개요

### 프로젝트명
서울시 공영주차장 검색 및 안내 프로그램

### 프로젝트 설명
서울 데이터 허브에서 제공하는 **서울시 공영주차장 안내 정보**를 활용하여
사용자가 원하는 조건에 따라 서울시 공영주차장을 검색하고 조회할 수 있는 프로그램을 구현한다.

공영주차장 데이터를 프로그램 내부 자료구조에 저장한 뒤,
자치구 또는 주차장명을 기준으로 검색하고 요금 및 주차면수 등의 조건으로
정렬하거나 추천 결과를 제공한다.

---

## 2. 사용 데이터

### Data Source
- 서울 데이터 허브 (Seoul Data Hub)
- 서울시 공영주차장 안내 정보

### 활용 예정 데이터
공영주차장 데이터 중 프로젝트 기능 구현에 필요한 항목을 선별하여 사용한다.

예정 항목:
- 주차장명
- 주소
- 자치구
- 주차면수
- 기본 요금
- 운영 시작 시간
- 운영 종료 시간

※ 실제 사용하는 데이터 필드는 데이터 분석 후 최종 확정한다.

---

## 3. 주요 기능

- 공영주차장 목록 조회
- 자치구별 주차장 검색
- 주차장명 검색
- 요금 기준 검색
- 운영시간 조회
- 요금 및 주차면수 기준 정렬
- 요금 기준 Top-N 주차장 추천

---

## 4. 자료구조 활용 계획

### 4.1 Vector

전체 공영주차장 데이터를 저장하는 기본 자료구조로 사용한다.

주요 연산:
- 주차장 데이터 삽입
- 전체 데이터 순회
- 인덱스를 이용한 데이터 접근

사용 이유:
서울 데이터 허브에서 읽은 여러 주차장 데이터를 순차적으로 저장하고,
검색 및 정렬 기능에서 공통으로 사용하기 위해 선택한다.

---

### 4.2 Hash Table

자치구 또는 주차장명을 기준으로 주차장을 검색하는 데 사용한다.

주요 연산:
- Key 삽입
- Key 검색
- 검색 결과 조회

예시:

```text
강남구
 ├─ 주차장 A
 ├─ 주차장 B
 └─ 주차장 C

광진구
 ├─ 주차장 D
 └─ 주차장 E
