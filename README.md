# DS-kwangwoon

광운대학교 자료구조 팀 프로젝트

## 프로젝트 주제
서울시 공영주차장 안내 프로그램

서울 데이터 허브에서 제공하는
'서울시 공영주차장 안내 정보' 데이터를 활용하여
사용자가 원하는 조건에 따라 공영주차장을 검색하고 조회할 수 있는 프로그램을 구현한다.

## Data Source
- 서울 데이터 허브 (Seoul Data Hub)
- 서울시 공영주차장 안내 정보

## 주요 기능
- 공영주차장 목록 조회
- 자치구별 주차장 검색
- 주차장명 검색
- 요금 기준 검색
- 운영시간 조회
- 조건별 정렬

## 개발 환경
- Language: C++
- Version Control: Git / GitHub
